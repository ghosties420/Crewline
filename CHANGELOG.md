# 1.4 — Android usability and convoy controls

See UPDATE-1.4.md for all changes and installation instructions.

# 1.3.0 — convoy planning and radio

- Map meeting/destination pin selection, one-shot device location, draggable pins and up to five stops.
- Crew-only or public visibility, scheduled departure, participant readiness, begin/finish controls and navigation handoff.
- Event-to-convoy prefill with private-event disclosure restrictions.
- Joined-member internet radio with default-muted hold-to-talk, speaker control and native transmit timeout.
- Convoy reporting and server permission tests. Existing convoys retain crew-only visibility.
- Server protocol 4; Android version code 130. Update both server and app.

# 1.2.1 — cameras on the map

- Map displays all fixed-camera records from the same local database as alerts.
- Distinct speed, red-light and average-speed endpoint markers with tap details.
- Persistent show/hide control and View all cameras overview.
- Map markers do not enable GPS or audible alerts; Explore fog remains unchanged.
- Android version code 121. Server remains 1.2.0 / protocol 3; no server upgrade required.

# 1.2.0 — community pilot

- Individual accounts plus multiple crew memberships, application approval and organiser roles.
- Public and private events, RSVPs, crew invitations/acceptance/revocation and shared event discussion.
- Private legacy content migrates to Original crew; all new accounts begin without a crew.
- Board, group chat, calls, live locations and convoys restricted by crew membership.
- Contact preferences, blocking, reporting, moderator/admin dashboards, bans and audit logs.
- Invite-only/open registration controls, privacy/support contact, rules disclosure and one-use recovery codes.
- Offline phone-side approach warnings using 133 published NZTA fixed-camera records; manual validated dataset updates.
- Photo/vehicle limits, local health monitoring, daily backups, guarded restore tooling and private signing workflow.
- Android version code 120, API protocol 3. Update server and all phones together.

The existing update APK remains test-signed. Public exposure, production signing, real-phone tests and operational restore rehearsal remain host tasks. No claim of nationwide capacity or complete camera coverage.
