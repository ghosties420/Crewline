This SSH session runs inside Crewline Admin. For a private Tailscale server, install and connect Tailscale inside this GrapheneOS profile. Each profile has its own VPN and app credentials.

The app creates a separate SSH key for each GrapheneOS profile. Your private key stays encrypted in that profile using Android Keystore. Verify the server's fingerprint on first connection.
