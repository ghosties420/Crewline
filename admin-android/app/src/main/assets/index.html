Private SSH terminal

SSH connection

Use the private Tailscale hostname or address of your Linux server. This opens a trusted SSH client on your phone; an embedded terminal is not implemented yet.

No SSH password or private key is stored by Crewline Admin. Keep SSH restricted to your tailnet and use key-based authentication.

Useful server commands

Run these only after connecting to the right server.

sudo systemctl status crewline
sudo journalctl -u crewline -n 100
sudo bash deploy/health-check.sh

Restarts, deploys and database restores remain manual terminal operations to prevent accidental downtime.
